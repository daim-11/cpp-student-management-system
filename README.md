# Student Management System

A console-based Student Management System developed in **C++** to manage student records through a structured, menu-driven interface. The project demonstrates practical implementation of Object-Oriented Programming, data management, input validation, searching algorithms, and file handling.

## Overview

The application provides a simple way to maintain student information while ensuring that records can be stored and retrieved across program executions.

It was developed as a C++ portfolio project to demonstrate core programming and software development concepts.

## Key Features

- **Student Registration:** Add new student records with relevant information.
- **Record Management:** View, update, and delete existing student records.
- **Search Functionality:** Find individual students using their unique ID.
- **Persistent Storage:** Store and retrieve records using file handling.
- **Input Validation:** Handle invalid user input to maintain reliable operations.
- **Menu-Driven Interface:** Navigate system operations through a simple console interface.

## Technical Implementation

| Component | Implementation |

## Getting Started

### Prerequisites
- A C++ compiler (GCC, MinGW, or equivalent)
- Visual Studio Code or another C++ development environment

### Installation & Execution

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd Student-Management-System
```

3. Compile the source code:

```bash
g++ main.cpp -o StudentManagementSystem
```

4. Run the application:

```bash
./StudentManagementSystem
```

On Windows:

```bash
StudentManagementSystem.exe
```
